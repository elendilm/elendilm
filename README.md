Hacker News username: "elendilm"

Starting in early 2014, I moved on to building an entire custom offline-first + online-sync distributed ERP application from scratch until the end of the decade, tackling distributed systems and conflict resolution before production CRDT implementations existed. This later led to building Slyp, SlypBusiness, a custom database, Feature Architecture, and an ecosystem of core technologies:

• Slyp: Regional shopping app (Status: Ready to launch).

• SlypBusiness: App enabling brands to promote outlets with commission tied to actual sales, not views or reach (Status: Ready to launch).

• Dip: Parallel database substrate with raw binary and JSON as co-equal first-class citizens, featuring per-request KV engine selection. Forms the backbone of Slyp & SlypBusiness.

• Monolog: Lightweight Kafka-like log broker built on Dip and runs on servers and mobile alike.

• Singularity: Key-value engine.

• ARCC: Architecture compiler.

• Craft: Mobile app for app development using flowcharts, snippets, and a WYSIWYG designer (Status: MVP).

• Portal: Mobile app for remote container management and HITL AI workflows (Status: MVP).
